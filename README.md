# Nina Klishevich — Digital Business Card

A single-page digital business card, hosted on GitHub Pages.

- **`index.html`** — the card (self-contained; the LinkedIn QR code is embedded).
- **`contact.vcf`** — the contact file the **Save Contact** button downloads. Tapping it on a phone opens the native "Add Contact" screen.

## Live card

Once GitHub Pages is enabled, the card is live at:

```
https://<your-username>.github.io/business-card/
```

## Updating details

Edit `index.html` for what's shown on screen, and `contact.vcf` for what gets saved to a phone. Keep the two in sync.
